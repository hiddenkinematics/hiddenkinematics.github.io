# Learning to Explore Hidden Kinematics for Articulated Object Manipulation

Project page. Served with GitHub Pages from the root of the `main` branch (`index.html`).

- `index.html` — the page (self-contained HTML/CSS; KaTeX and Google Fonts from CDN)
- `static/images/` — paper figures
- `static/videos/` — simulation gallery (IsaacGym view | point cloud + articulation flow), H.264
- `static/media/` — teaser, method animations, ArticuRiddle pairs (from the slide deck, re-encoded to H.264)
- `static/riddle3d/` — ArticuRiddle pairs for the 3D viewer (GLB per pair + opening keyframes), made by `tools/export_pairs.py` from `riddle_pairs_render/`
- `static/posters/` — video poster frames

To preview locally: `python3 -m http.server` and open http://localhost:8000.
